## Neuro-SaaS

Neuro-SaaS is a modern full-stack AI-powered analytics dashboard built with the MERN stack. The project focuses on real-time analytics, user management, activity tracking, authentication, and responsive dashboard design with a clean user experience.

### Features

* Real-time analytics dashboard
* Interactive charts & statistics
* User management system
* Activity tracking feed
* Authentication system
* Dark/Light mode support
* Fully responsive UI

### Tech Stack

* React.js + Vite
* Tailwind CSS
* Framer Motion
* Node.js + Express.js
* MongoDB
* Axios
* Render Deployment
